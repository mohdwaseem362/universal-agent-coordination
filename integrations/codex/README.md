# Codex CLI Integration Guide

1. **Install via UAC CLI**:
   ```bash
   node ./bin/uac.js install --level 2
   ```
2. **Generated Files**:
   - `.codex/config.toml`: Registers `[mcp_servers.universal_agent_coordination]`.
   - `AGENTS.md`: Safely merges sentinel block teaching `@followprotocol <task>`.
   - `skills/universal-agent-coordination/SKILL.md`: Canonical Agent Skill definition.
